# P.A.L.
Portable Ambient Link


UPCOMING PROJECT

Summary

This device is intended as a visualizer for audio playback for a linked device. While not connected, the device can be configured to show the current time, weather, live updates or other custom views. When connected and playing audio, the device adapts to display the artwork of the currently playing song. It will also include a player UI so the track can be paused or changed from the touchscreen display. Potentially, a music visualizer and other views can be configured (such as a photo slideshow).
